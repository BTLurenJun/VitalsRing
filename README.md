# VitalsRing（环脉）

> 一个 Windows 11 桌面小工具：无边框置顶小窗，用五个自绘环形实时显示电脑状态。

**当前版本：0.10.08.01**（版本号规则：`0.10.轮次.修改次数`）

## 功能特性

| 能力 | 说明 |
|---|---|
| 🎯 **五环实时监控** | CPU、GPU、内存、C 盘、齿轮（设置），环长随占用变化，2 秒刷新 |
| 🧩 **槽位可自由配置** | 五个位置任意换成其它数据项（含 D 盘、总盘、电池等） |
| 🖥️ **双形态** | 任务栏挂件（188×44）与大面板（约 320×320）一键切换，带过渡动画 |
| 📌 **任务栏吸附** | 自动贴任务栏左侧、置顶不遮挡；吸附状态下不可拖走，避免误触 |
| 🔒 **设置锁** | 锁定后改动立即写盘、重启保留；解锁则仅本次运行生效 |
| 🐞 **调试模式** | 手动拉数值预览环效果，不写盘、关窗即失效 |
| 🎨 **深浅双主题** | 跟随系统明暗自动切换，浅色主题单独做过对比度校核 |
| 🧊 **Win11 圆角** | 设置窗口走 DWM 圆角，并带 Qt 遮罩兜底，二次打开也不丢 |
| ⚡ **轻量** | 空闲时 CPU 接近 0%、内存稳定，长时间挂机不增长 |

## 环境要求

- Windows 11（Win10 亦可运行，圆角等效果按系统能力降级）
- Python 3.10+（仅源码运行需要）
- PyQt6 ≥ 6.6、psutil ≥ 5.9；`pynvml` 可选（缺失时自动降级到 `nvidia-smi`）

## 快速开始

```bat
:: 双击项目根目录的「启动.bat」即可（自动使用项目内 .venv）
启动.bat
```

首次运行若 `.venv` 不存在，`启动.bat` 会自动创建并安装依赖。

## 手动安装与运行

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

## 打包为 exe

```bat
:: 双击 build_exe.bat，产物在 dist\VitalsRing\VitalsRing.exe
build_exe.bat
```

- 单目录 + 无控制台（`--onedir --windowed`），不生成单文件
- 已剔除未使用的 Qt 模块（QtNetwork / QtQml / QtQuick / QtWebEngine / QtSql / QtMultimedia 等）
- 若本机存在 `upx.exe`，脚本会自动启用 UPX 压缩；没有则跳过
- 配置文件 `vitalsring_config.json` 生成在 **exe 同目录**，不会写进 `_internal`

## 操作方式

| 操作 | 效果 |
|---|---|
| 左键单击数据环 | 挂件形态弹出详情窗；大面板形态切换环形/文字列表 |
| 左键单击齿轮 | 打开/关闭设置窗口（按下即响应） |
| 按住拖动 | 挂件未吸附时可移动；吸附时不可拖动 |
| 右键单击 | 弹出菜单（设置… / 退出）——挂件唯一的退出入口 |
| 关闭控制台窗口 | 直接结束进程（无控制台版不受影响） |

## 设置窗口

四个分页，1080P 下每页均无需滚动：

1. **常规与外观** —— 界面模式、显示刻度、拟物化图标、图标风格、任务栏吸附、恢复默认
2. **性能与检测** —— CPU / GPU / 内存 / C 盘 / 电池检测开关、五槽位环配置
3. **高级调试** —— 调试模式与各项调试值（不持久化，关窗复位）
4. **关于** —— 系统信息、作者与仓库、制作人员署名、版本号

## 验证要点

1. **无数字**：环形区域内看不到任何数字。
2. **实时性**：打开任务管理器对比，弧长随刷新变化（GPU 环走 `pynvml`，不调用 `nvidia-smi`）。
3. **失败显示**：既无 `pynvml` 又无 `nvidia-smi` 时，GPU 环显示灰空环 + 红叉 + “不支持”。
4. **槽位**：挂件与大面板共用同一套槽位配置；齿轮位在文字列表中跳过。
5. **版本号**：窗口右下角显示 `版本 0.10.08.01`，设置窗口「关于」页显示 `0.10.08.01`。
6. **窗口行为**：无系统标题栏、始终置顶、不出现在 Alt+Tab、点击不抢焦点。
7. **占用**：空闲 CPU 约 1% 以内，挂机 10 分钟内存基本持平。
8. **设置窗口**：四个分页切换流畅；连续开关 10 次位置不漂移、圆角不丢。

## 性能与资源占用

- 数据刷新：2 秒一次，仅在数值变化时重绘
- 空闲时不做多余计算；无网络请求、无后台服务
- 设置窗口按需创建并预热，首次打开延迟约 60ms

## 已知问题

- **混合 DPI 多显示器**：跨不同缩放比例的屏幕拖动时可能出现一次跳位，松手会收回屏幕内。
- **低分辨率**：可用高度不足时设置窗口允许滚动（分页内容已尽量压缩）。
- **截图工具**：第三方截图若长时间阻塞事件循环，设置窗口的弹出动画可能短暂停在半透明，恢复后自动收敛。

