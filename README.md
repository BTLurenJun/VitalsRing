# VitalsRing（环脉）

作者：`https://github.com/BTLurenJun`

一个 Windows 11 桌面小工具：无边框置顶小窗，用五个自绘环形显示电脑状态。

当前版本：**0.10.07.22**（版本号规则：`0.10.轮次.修改次数`）

## 已完成的功能（第 1～7 轮）

- 无边框、无标题栏、置顶、不抢焦点、尽量不出现在 Alt+Tab，支持鼠标拖动移动窗口。
- 背景优先深色半透明圆角；半透明不可用时自动降级为系统着色颜色，取色失败则用固定深灰。降级后仍保持圆角与无边框，且不会出现系统白条或四角露底色。
- 五个 QPainter 自绘环，挂件与大面板共用同一套槽位配置，顺序由「环配置」决定；默认 **CPU → GPU → 内存 → C盘 → 齿轮**。
- 每个环 = 灰色底环 + 低对比度刻度线 + 彩色进度弧；弧从正上方开始顺时针增长。（刻度线默认关闭，可在设置窗口「外观」里勾选「显示环形刻度」开启。）
- 环形区域内**不出现任何数字**：刻度线不带数字标签，环中心只显示拟物化图标或项目名称。
- 颜色规则：<60% 绿，60%~85% 黄，>85% 红；电池 <20% 红，充电中显示蓝色。
- 失败项统一显示：灰色空环 + 刻度 + 红色叉号（只覆盖环形区域，不盖住中心文字），环下方显示原因。
- 环形下方两个文本行：`开机时长：X小时X分钟`、`系统版本：Windows 11 XXX`，**可点击折叠**。
- **点击任意数据环**：当前槽位中的数据项整体切换为文字列表（齿轮位跳过；文字模式显示"名称 + 百分比"，失败项显示"名称 + 原因"）。
- **再点击任意文字行**：切回环形模式（环形模式始终不显示任何百分比和刻度数字）。
- **点击"开机时长"或"系统版本"行**：折叠/展开该行内容，折叠后只留标题。
- 切换与折叠状态**不持久化**，重启后默认环形模式、两行均为展开。
- **点击右下角小齿轮**：打开"设置与调试"窗口（齿轮始终显示，不参与环形/文字切换）。
- **调试模式**：默认关闭；关闭时各项调试子控件全部置灰不可点，旁显示"请先开启调试模式"。调试模式期间暂停真实读取（2 秒定时器停止），关闭调试或关闭设置窗口后立即恢复。
- **各项调试值**：每项有 0~100 滑块、数值输入框、"应用调试值""恢复真实值"，仅在调试模式开启时生效；动态磁盘与总盘同样可调试。
- **各项启用检测开关**：默认全开；关闭某项后对应环显示红叉 + "检测已关闭"，重新开启恢复。
- **GitHub 按钮**：点击"打开 GitHub 仓库"会打开本项目的 GitHub 页面（地址见文末"仓库地址"）。
- 关闭设置窗口（X / Esc / 隐藏均可）会自动关闭调试模式、子控件置灰、主窗口立即恢复真实数据刷新；调试值关闭即清空，检测开关在本次运行内保留（重启后恢复全开）。
- **任务栏吸附（第二阶段）**：默认自动贴到任务栏左侧、垂直居中；任务栏自动隐藏时面板跟随隐藏，全屏程序运行时自动隐藏、退出后恢复；分辨率/DPI 变化与 Explorer 重启后自动重新定位。
- **双模式界面（默认挂件）**：任务栏挂件模式（默认）与大面板模式，可在设置窗口切换；锁上设置时重启保留。
- **挂件背景按吸附状态自适应**：已吸附且系统开启透明效果时全透明（直接透出任务栏材质）；未吸附时退回深色圆角背景，保证文字可读。
- **挂件五环**：5 个槽位全部可配，可选「CPU / GPU / 内存 / C盘 / 总盘 / 各固定磁盘 / 电池 / 齿轮」，五项互不重复（默认 CPU + GPU + 内存 + C盘 + 齿轮）。点击齿轮收起/打开设置，点击其它环或缝隙弹出详情窗口（详情按当前槽位动态展示，齿轮位跳过）。
- **拟物化图标（第 7 轮）**：支持「多色拟物」（默认，半透明填充 + 微渐变 + 高光）与「单色线条」（1.2px 描边）两种风格，可在设置「外观」切换并受锁控制；CPU / GPU / 内存 / 磁盘 / 总盘 / 电池六类图标与进度弧、绿黄红配色共存，GPU 在任何尺寸下都不画放射线扇叶。
- **零抖动双风格**：所有结构由唯一 `_build_icon_path()` 生成 QPainterPath；单色只 `strokePath`，多色 `fillPath` 后再 `strokePath`，外沿统一 1.2px，切换时物理边缘 100% 重合。GPU 3 根 0.08d 金手指、内存 4 根 0.04d 金手指全部外凸。
- **电池分段**：图标内 3 格按真实电量点亮（≥67% 3 格、≥34% 2 格、>0 1 格）；多色为绿色发光，单色为白色实心 / 虚线框。
- **现代化设置窗口**：左右双列布局（约 700×750，调试值展开后仍 ≤750、无垂直滚动），底部 5 个槽位下拉横排；深色圆角卡片 + 阴影、iOS 滑动开关、无边框下拉（▾）、圆角按钮、Emoji 标题。调试值卡片内嵌左列，双列 7 项 + 「应用全部 / 恢复全部」全局按钮。
- **动画与拖动（0.10.07.13 收敛）**：ToggleSwitch 250ms OutExpo 位移 + 挤压拉伸（InExpo 末段回弹正圆）；调试值卡片 maximumHeight 0↔220，250ms OutExpo，内容 opacity 延迟 50ms / 250ms，并加 350ms 强制收敛保险；设置窗口仅淡入 0→1 + 上浮 15px（250ms OutExpo，不再缩放宽高），失焦/截图或 400ms 超时强制回到最终几何；按钮 120ms OutQuad 阴影回弹；调试滑块拖动实时跟手，点击轨道 100ms OutCubic 平滑过渡。
- **SSD / HDD 智能识别**：启动时用只读 Win32 IOCTL 查询每块固定盘的 SeekPenalty 属性，自动区分 SSD 与 HDD；探测失败或权限不足时默认按 SSD 显示，不影响界面。
- **磁盘图标**：SSD 画 M.2 长条 + 2 个芯片，HDD 画方形底座 + 同心盘片；C盘（系统盘）中心偏右上带 2.5px 实心圆点，D盘为纯空心盘片，34px 下也能区分。
- **动态磁盘**：自动枚举固定磁盘（过滤光驱、可移动盘、空文件系统），每块盘单独成项，并提供「总盘」= 所有固定磁盘 used 之和 / total 之和。
- **设置锁**：设置窗口顶部 🔒/🔓 按钮。锁上后界面模式、刻度、槽位修改立即写入项目根目录 `vitalsring_config.json`，重启保留；解锁后只在本次运行生效，重启恢复默认。调试模式永远不保存。
- **恢复默认设置**：设置窗口底部按钮，内容区淡出 200ms → 重置 → 淡入 200ms。
- 右下角显示 `版本 0.10.07.22`。
- 在窗口上单击右键可弹出菜单退出程序（本窗口无边框、不进任务栏，这是唯一的退出入口）。
- 每 2 秒刷新一次，数据读取与界面绘制分离，只读系统信息。

两阶段计划已全部完成。

## 已知问题（Known Issues）

- **混合 DPI 多显示器拖动**：0.10.07.13 按要求把主面板拖动改为固定 `_drag_offset` 绝对定位，同 DPI / 单屏下手感正常；跨到缩放比例不同的屏幕时，Qt 会按比例重算逻辑坐标，可能出现一次跳位。松手会统一做一次屏幕内收回，不会丢窗口；若后续影响使用，应回退为增量位移方案。
- **低分辨率下的设置窗口高度**：`700×750` 依赖屏幕可用高度 ≥ 830px。1280×720 / 1366×768 等机器上会按「可用高度 - 80」限高，可能出现垂直滚动条，这是为避免压住任务栏而保留的降级行为。
- **截图/失焦自检为模拟触发**：自动化测试通过 `ActivationChange` 事件 + 400ms 强制收敛验证；Ctrl+Alt+A 等第三方截图工具若既不触发失焦、又长时间阻塞事件循环，打开动画可能短暂停在半透明，事件循环恢复后由保险定时器收敛。未在真实截图工具下自动化实跑。
- **effect 父子叠加**：调试卡内部已彻底去嵌套（`rows_inner` 无 effect、`rows_card` 仅一个 opacity）；但设置窗口的 QGroupBox 阴影与子按钮阴影仍是父子 effect 叠加。每个 widget 仅有一个 effect，实测 20 次开关无重影；极低端 GPU 上大量阴影可能有轻微绘制开销。

## 环境要求

- Windows 11
- Python 3.10 及以上（本机验证环境为 Python 3.13.12）

## 运行（推荐：双击启动）

**直接双击项目根目录下的 `启动.bat` 即可。** 不需要敲任何命令。

这个脚本会自动完成：

1. 使用项目内的 `.venv` 虚拟环境运行 `main.py`（不污染全局环境）；
2. 如果 `.venv` 不存在，自动创建虚拟环境，并按 `requirements.txt` 安装 PyQt6、psutil、pynvml（首次需要联网）；
3. 如果运行出错，窗口会停住等待按键，不会一闪而过，方便看清错误信息。

程序启动后窗口默认出现在屏幕右上角。

> 说明：`启动.bat` 用 GBK 编码保存，如果在编辑器里打开看到乱码属正常现象，
> 直接双击运行不受影响。

## 手动安装依赖与运行（可选）

> 依赖清单：`PyQt6`（必需）、`psutil`（必需）、`pynvml`（可选，仅用于读取 NVIDIA GPU）。
> 当前本机已实际安装：`PyQt6`、`psutil`、`pynvml`；除这三个之外不引入任何第三方库。

推荐在项目内创建虚拟环境，不装到全局、不改 PATH、不请求管理员权限。

```powershell
# 在项目根目录执行
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 运行
python main.py
```

> GPU 说明：已安装 `pynvml` 时，GPU 环走 NVML 路径，与其它四项一样每 2 秒刷新，
> 且不会去启动 `nvidia-smi` 子进程（因此没有主线程阻塞风险）。

## 验证要点

1. **无数字**：环形区域内看不到任何数字（刻度线无标签，环中心只有图标或名称）。
2. **顺序**：挂件与大面板共用槽位配置；默认从左到右是 CPU、GPU、内存、C盘、齿轮，齿轮位在文字列表中跳过。
3. **实时性**：打开任务管理器对比，弧长随 2 秒刷新变化（GPU 环同样 2 秒刷新，走 `pynvml`，不调用 `nvidia-smi`）。
4. **失败显示**：GPU 项在既没有 `pynvml` 又没有 `nvidia-smi` 的环境下显示灰空环 + 红叉 + "不支持"（本机已装 `pynvml`，显示真实占用率）；台式机无电池时电池环显示红叉 + "无电池"。
5. **版本号**：窗口右下角显示 `版本 0.10.07.22`，设置窗口底部显示 `版本 0.10.07.22`。
6. **窗口行为**：无系统标题栏、始终置顶、不出现在 Alt+Tab、点击窗口不会抢走其他程序的输入焦点。
7. **占用**：任务管理器中该进程空闲 CPU 约在 1% 以内，挂机 10 分钟内存基本持平。
8. **点击切换**：大面板模式下点任意数据环 → 当前槽位中的数据项变成文字行（齿轮位跳过）；再点任意文字行或空白处 → 变回五环。
9. **折叠**：点"开机时长"行 → 只剩标题"开机时长"；再点一次恢复完整内容。"系统版本"行同理。
10. **调试置灰**：打开设置窗口，调试模式默认关闭，各项滑块 / 数值框 / 两个按钮全部灰掉点不动，旁边显示"请先开启调试模式"；总开关本身始终可点。
11. **调试值**：勾选调试模式后子控件可用；把某项拖到 90 再点"应用调试值"，主窗口对应环明显变长（超过 85% 会变红）；点"恢复真实值"回到真实读数。
12. **检测关闭**：在设置窗口取消勾选某项"启用检测"，主窗口对应环立即变灰 + 红叉 + "检测已关闭"；重新勾选恢复真实显示。
13. **关闭复位**：用 X 或 Esc 关闭设置窗口，主窗口立刻恢复真实数据并在 2 秒节奏上继续跳动；再次打开设置窗口，调试模式仍是关闭状态、滑块回到真实值。
14. **GitHub 按钮**：点"打开 GitHub 仓库"会用默认浏览器打开本项目仓库页面。
15. **任务栏吸附**：启动后面板自动贴在任务栏左侧并垂直居中；鼠标拖一下面板即自动切回手动模式，设置窗口里的"自动吸附到任务栏"复选框会同步取消。
16. **自动隐藏 / 全屏**：任务栏开启自动隐藏时，鼠标离开屏幕底部面板会一起隐藏；全屏程序运行时自动隐藏，退出全屏后恢复显示。
17. **定位失败回退**：找不到任务栏时面板保持可拖动，设置窗口会显示"未找到任务栏，已回退为手动拖动"。
18. **界面模式**：设置窗口「界面模式」默认选中"任务栏挂件模式"；切到大面板后恢复两行文本、折叠、文字列表与缩放手柄，且不吸附。
19. **环配置（挂件 / 大面板）**：5 个下拉，每个只列出未被其它槽占用的候选（含齿轮）；挂件与大面板共用同一套配置，大面板模式下同样可改；改动任一槽后其余下拉立即刷新；点「恢复默认环配置」回到 CPU / GPU / 内存 / C盘 / 齿轮。
20. **详情窗口**：点挂件数据环弹出约 200×190 的详情窗，内容按当前槽位动态展示（齿轮位跳过），点任意位置或 Esc 关闭。
21. **磁盘枚举**：磁盘列表在启动时枚举，插拔硬盘 / U 盘后请重启程序才能看到新盘。
22. **图标风格**：设置「外观」默认勾选「使用拟物化图标」，图标风格默认「多色拟物」；可切换「单色线条」，挂件与大面板立即同步重绘。取消勾选后恢复项目名称文字。某项检测关闭时该环只显示红叉，不残留图标。
23. **SSD/HDD**：启动日志或离屏脚本可打印 `disk_c / disk_d` 的 `disk_type`（ssd/hdd）；SSD 显示 M.2 长条，HDD 显示方形盘片 + 磁头臂。
